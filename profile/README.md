## 01. About Us | 关于我们

**WZH GAME** 是一个专注于 AI 辅助游戏开发、3D 交互体验和独立游戏技术探索的开发组织。

我们致力于探索人工智能与游戏开发的结合，让游戏创作更加高效、灵活和开放。

从最初的创意构思，到游戏逻辑、角色系统、3D 场景，再到测试、优化与部署，我们希望建立一套更加智能化的游戏开发流程。

**WZH GAME** is an independent game development organization focused on AI-assisted creation, 3D interactive experiences, and browser-based game technologies.

Our goal is to explore how AI can make game creation more accessible, efficient, and innovative.

## 02. AI Game Creation | AI 游戏创作

### 从一句话创意，到可玩的游戏

我们正在探索 AI 驱动的游戏创作工作流。

开发者可以通过自然语言描述游戏创意，让 AI 辅助完成从设计到实现的多个开发环节。

| 开发阶段 | AI 辅助能力 |
|---|---|
| 创意策划 | 将一句话创意转化为游戏设计方案 |
| 玩法设计 | 生成游戏规则、任务和交互逻辑 |
| 程序开发 | 辅助生成 HTML、JavaScript、TypeScript 代码 |
| 3D 世界 | 辅助创建场景、地图和游戏对象 |
| 角色系统 | 设计角色、NPC 和智能交互 |
| 关卡设计 | 辅助构建地图、障碍和挑战 |
| 测试优化 | 辅助发现问题、修复错误和优化性能 |
| 项目交付 | 整理项目文件并支持网页部署 |

### AI Development Vision

Our long-term vision is to build a more intelligent game development workflow:

**Idea → Design → Generate → Build → Test → Optimize → Deploy**
